## Requirements

- Windows 10 or Windows 11, **64-bit**
- 4 GB RAM minimum — 8 GB or more recommended for local models
- Optional: [Ollama](https://ollama.com) for local models
- Optional: Git on `PATH` for source control

## First launch

1. **File → Open Folder** and pick a project.
2. Open **Model Manager** (`Ctrl+Shift+M`) and configure one provider.
3. Select a model in the AI panel and start in **ASK** mode.

> Builds are not code-signed, so Windows SmartScreen may warn on first launch.
> Choose **More info → Run anyway**.

Data lives in `%APPDATA%\PIKO AI`. Uninstalling keeps your memory and settings by default.
